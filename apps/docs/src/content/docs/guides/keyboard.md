title: Keyboard shortcuts
description: Everything you need without reaching for the mouse.
---

HABI is usable from the keyboard. Every interactive control has a visible focus
state, dialogs trap focus and return it when they close, and the file tree is a
real tree you can navigate with arrow keys.

## Global

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd + S` | Save and rebuild |
| `Ctrl/Cmd + R` | Rebuild |
| `Ctrl/Cmd + Enter` | Open the viewer |
| `Ctrl/Cmd + P` | Quick open a file |
| `Ctrl/Cmd + Shift + P` | Command palette |
| `Ctrl/Cmd + B` | Toggle the file tree |
| ``Ctrl/Cmd + ` `` | Toggle the bottom panel |

## In the editor

Find, replace, multi-cursor, formatting and folding are Monaco's own, and work
as they do in VS Code.

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd + F` | Find |
| `Ctrl/Cmd + H` | Replace |
| `Alt + Click` | Add a cursor |
| `Shift + Alt + F` | Format the document |

## In the file tree

| Key | Action |
| --- | --- |
| `Up` / `Down` | Move between files |
| `Right` | Expand a folder, or move down |
| `Left` | Collapse a folder, or move to the parent |
| `Enter` | Open a file, or toggle a folder |
| `F2` | Rename |
| `Delete` | Delete |

Deleting a folder that has contents asks first. Deleting a single file does not.

## In tabs

| Key | Action |
| --- | --- |
| `Left` / `Right` | Move between open tabs |
| `Ctrl/Cmd + W` | Close the focused tab |
| Middle click | Close a tab |
