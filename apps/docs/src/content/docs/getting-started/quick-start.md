## 1. Create a project

Open the playground and choose **New project**. Pick a template:

| Template | What you get |
| --- | --- |
| HTML, CSS & JavaScript | `index.html`, `styles.css`, `script.js` |
| React + TypeScript | `src/main.tsx`, `src/App.tsx`, `src/styles.css` |
| React + JavaScript | The same, without type annotations |
| React + Motion | Animation and smooth scrolling, using the provided libraries |
| React + Tailwind CSS | React with the Tailwind browser runtime enabled |
| Blank | One component and a stylesheet |

No account is required. The project is saved in this browser as you type.

## 2. Edit

The file tree is on the left, tabs across the top, and the console below. Type
anywhere and the project recompiles after a short pause — you do not need to
press anything.

Save happens on its own too. `Ctrl/Cmd + S` forces both a save and a rebuild if
you would rather be explicit.

## 3. See it run

There are two ways to look at your application:

- **Preview panel** — the third tab in the bottom panel, next to Console and
  Problems. Useful while you are still typing.
- **Viewer** — press **Open viewer** in the header, or `Ctrl/Cmd + Enter`. Your
  application gets a whole page, with device presets and fullscreen.

## 4. Share it

Press **Share**. You get a link to the viewer that anyone can open without an
account and without installing anything.

If HABI has no backend configured, the project is packed into the link itself,
so the page works with nothing behind it. See [Sharing](/guides/sharing/).
